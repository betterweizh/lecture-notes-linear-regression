# 符号说明

下表列出多章通用的符号。引入新符号的章节在本章的“符号说明”部分另行列出。

| 符号 | 含义 |
|---|---|
| $n$ | 观测数 |
| $k$ | 预测变量个数（不含截距） |
| $p$ | 回归系数个数；含截距时 $p = k + 1$ |
| $y_i$, $\by$ | 响应变量观测值；响应向量，属于 $\R^n$ |
| $\bx_i$, $\bX$ | 第 $i$ 个观测的预测变量向量；设计矩阵，属于 $\R^{n\times p}$ |
| $\bbeta$, $\widehat{\bbeta}$ | 系数向量及其估计量 |
| $\bvarepsilon$, $\be$ | 不可观测的误差与可观测的残差 |
| $\bH$ | 帽子（投影）矩阵 $\bX(\bX\T\bX)^{-1}\bX\T$ |
| $\mu_i$, $\eta_i$ | 条件均值 $\E[Y_i\mid\bx_i]$ 与线性预测子 $\bx_i\T\bbeta$ |
| $\lambda$ | 岭回归和 lasso 回归中的惩罚（调节）参数 |
